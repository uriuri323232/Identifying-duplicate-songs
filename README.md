# Duplicate Song Finder (Android, offline)

אפליקציית אנדרואיד שסורקת את כל השירים במכשיר (דרך MediaStore), מזהה כפילויות לפי
דמיון בשם הקובץ (fuzzy) בשילוב טווח סטייה באורך השיר, ומאפשרת לנקות אותן.
הכול רץ מקומית — בלי רשת ובלי שרת.

## יכולות
- סריקה עם אחוזי התקדמות, ומסך תוצאות מלא נפרד שכל הכלים בו (חיפוש, מיון, סימון) גוללים יחד עם הרשימה, כדי שיהיה מקסימום מקום לתוצאות
- **סימון "לא כפולים"**: אם שני שירים דומים אבל שונים באמת — מסמנים, והאפליקציה זוכרת
  (גם אחרי סגירה) ולא תציג אותם ככפולים בסריקות הבאות. אפשר לבטל סימונים במסך ייעודי
- הקשה על שיר פותחת אותו בנגן ברירת המחדל כדי לוודא
- נתיב מלא לכל קובץ, גודל, אורך, וסימון ⭐ לגרסה הגדולה ביותר
- העברה לפח (Android 11+) במקום מחיקה לצמיתות, עם אישור לפני
- **סרגל ניווט תחתון** (סריקה / תוצאות / פח עם מונה) בכל המסכים הראשיים, וכפתור "חזור" של המערכת מחזיר למסך הראשי במקום לסגור את האפליקציה
- **מסך פח פנימי** (Android 11+): כפתור פח עם מונה בכל מסך ראשי, ובהודעה אחרי העברה לפח. אפשר לסמן הכול, לשחזר או למחוק לצמיתות
- **"סמן הכול"** גם במסך התוצאות (כל השירים המוצגים, או קבוצה אחת) ובמסך "לא כפולים" (עם ביטול סימון למסומנים)
- **"סמן הכול"** בחלון "אלה לא באמת אותו שיר?" כדי לסמן קבוצה שלמה כ"לא כפולים" בלחיצה אחת
- ערכות רגישות מהירות (מדויק / מאוזן / רחב), מצב כהה, ממשק RTL
- אייקון חדש (כולל אייקון נושא ל-Android 13+)
- **חיפוש ומיון** במסך התוצאות (לפי מקום שיתפנה / מספר כפולים / א-ב)
- **סימון לפי תיקייה** – בוחרים תיקייה ומסמנים את כל הכפולים שבה (בלי למחוק שיר לגמרי)
- **"השאר רק את הטוב ביותר"** בכל קבוצה בלחיצה אחת
- **אזהרת בטיחות** לפני מחיקה אם נבחרו כל העותקים של שיר
- הצגת קצב סיביות משוער (kbps) ותגית "גודל זהה" לזיהוי עותקים זהים
- **ייצוא רשימת הכפולים** לשיתוף (וואטסאפ, מייל, הערות)
- **סטטיסטיקה מצטברת** של כמה קבצים ומקום נוקו עד היום
- ההגדרות (רגישות, פח) נשמרות בין הפעלות

## בנייה
הפרויקט נבנה אוטומטית ב-GitHub Actions (`.github/workflows/android-build.yml`) וחתום
בחתימה קבועה דרך ה-Secrets: KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD.
